# Seguridad y privacidad

No publiques credenciales ni conjuntos de datos privados en issues. Si GitHub ofrece «Report a vulnerability» en la pestaña Security, úsalo para un informe privado; si no aparece, abre un issue solicitando un canal privado sin incluir el contenido sensible.

Esta beta almacena trabajo en el navegador. Usa copias externas y revisa archivos importados y exportados. La aplicación no necesita claves de Supabase, Vercel, Sentry, n8n o Resend.

Actualizaciones de dependencias y correcciones se publicarán mediante versiones del repositorio. No se promete un plazo contractual de soporte.
